## Overview

D16 Group Spacerek is a clean algorithmic room reverb focused on natural-sounding spatial placement, from intimate small rooms to large concert halls.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **D16 Group Spacerek** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Room Modes** | Small, medium, and large room modes with realistic early reflections |
| **Decay Shaping** | Independent low and high frequency decay for bright or dark rooms |
| **Pre-Delay** | Up to 100 ms pre-delay separates direct and reverberant sound |
| **Modulation** | Subtle pitch modulation prevents metallic resonances in long decays |
